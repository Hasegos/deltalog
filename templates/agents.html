AI 에이전트에 연결

내가 쓰는 AI 에이전트(Claude Code, Cursor 등)에 Deltalog를 연결하면, 에이전트가 웹페이지를 긁어 오는 대신 Deltalog의 한국어 요약을 바로 조회합니다. 연결 주소는 {{ mcp }} 하나이고 MCP(Model Context Protocol) 서버입니다. 키 없이 읽기만 합니다.

이렇게 물어볼 수 있어요

  • 업그레이드 전에 "claude-code 2.1.290 쓰고 있는데, 지금 올리기 전에 꼭 봐야 할 변경이 있어?" → 그 사이 바뀐 점과 breaking · 보안 변경을 먼저 알려줍니다.
  • 종료 일정 "곧 종료되는 모델이나 API 있어?" → Anthropic, OpenAI, Google이 공식 문서에 예고한 종료 일정을 날짜순으로 알려줍니다.
  • 소식 "이번 주 OpenAI 공식 발표 중 중요한 것만 알려줘" → 제작사별 최신 소식을 중요도로 걸러 알려줍니다.
  • 도구 목록 "Deltalog가 추적하는 도구와 최신 버전을 알려줘"

연결 방법

Claude Code

claude mcp add --transport http deltalog {{ mcp }}

Cursor

설정의 MCP 파일(~/.cursor/mcp.json)에 추가합니다.

{
  "mcpServers": {
    "deltalog": { "url": "{{ mcp }}" }
  }
}

VS Code

작업 폴더의 .vscode/mcp.json에 추가합니다.

{
  "servers": {
    "deltalog": { "type": "http", "url": "{{ mcp }}" }
  }
}

Gemini CLI

~/.gemini/settings.json에 추가합니다.

{
  "mcpServers": {
    "deltalog": { "httpUrl": "{{ mcp }}" }
  }
}
